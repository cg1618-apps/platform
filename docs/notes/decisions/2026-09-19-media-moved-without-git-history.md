# `media` moved with no git history

`cgentle1618/anime_site` was not transferred or mirrored. `cg1618-apps/media`
starts from a single commit, and the old repository stays private as the
record.

**Rejected: transferring the repository, or mirroring its history.** The old
history is a single application's development, much of it about a deployment
that no longer exists. Carrying it would have meant carrying the box-level
parts that now belong to the platform.

So the old history is not grafted back in. A branch pushed from an old
`anime_site` checkout does exactly that, and is deleted rather than merged.
